# Andrus Giraldo — academic website

Static academic website designed for GitHub Pages. It uses plain HTML, CSS and a small amount of JavaScript, so there is no build step and no dependency installation.

## Edit the site

- Update biography and research areas in `index.html`.
- Add or edit papers in `publications.html`.
- Adjust colours, type and spacing in `styles.css`.
- Replace `assets/andrus-giraldo.jpg` with another portrait while keeping the same filename.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and the root folder, then save.

The site will appear at `https://<username>.github.io/<repository-name>/`.
